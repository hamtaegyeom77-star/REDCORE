# REDCORE FINAL

현재 파일만 열어도 동작하는 프론트엔드 쇼핑몰 데모입니다.

## 바로 확인
`index.html`을 브라우저에서 열면 됩니다.

## 이미 구현된 것
- 사진과 같은 방향의 REDCORE 미니멀/에디토리얼 홈 디자인
- 반응형 PC/모바일 레이아웃
- SHOP / 상품 상세
- 장바구니 수량 변경·삭제·합계
- 위시리스트
- 로그인/회원가입 데모(localStorage)
- 주문서 → 주문 완료 → 주문내역 흐름(localStorage)
- 고객센터 FAQ
- 공지 / 약관 / 개인정보 페이지 기본 틀
- 이미지가 없어도 깨지지 않도록 자체 SVG 비주얼 포함

## 출시 전에 반드시 직접/서버에서 해야 하는 것
1. 실제 회원 인증 서버 연결
2. 비밀번호를 localStorage에 저장하지 않는 안전한 인증 구조
3. 실제 PG(결제) 연동 및 결제 검증
4. 주문/재고/배송 DB 연결
5. 사업자 정보와 통신판매업 관련 고지사항 반영
6. 실제 이용약관·개인정보처리방침 확정
7. HTTPS/서버 보안/관리자 권한 설정
8. 실제 상품 사진, 가격, 재고, 배송 정책 입력
9. 도메인 연결 및 배포

※ 현재 결제 버튼은 실제 돈이 빠지는 결제 시스템이 아니라 주문 흐름을 테스트하는 데모입니다.
