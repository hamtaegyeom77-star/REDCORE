# REDCORE FINAL LOCAL STORE

이 버전은 REDCORE의 로컬 최종 테스트용 패키지입니다. 주문 페이지를 파일로 직접 열어도 localhost 주문 API에 연결되도록 보강했습니다.

## 실행
1. Node.js가 설치된 Windows PC에서 `REDCORE_START.bat` 더블클릭
2. 첫 실행 때 서버 패키지를 자동 설치
3. 브라우저에서 `http://localhost:3000/` 자동 실행
4. 상품 → 사이즈 → 장바구니 → 주문 → 주문번호 생성 테스트
5. 주문이 끝나면 주문번호가 표시됩니다.
6. 관리자: `http://localhost:3000/admin.html`
   - 기본 로컬 관리자 키: `local-admin-change-me`

## 포함
- 전체 REDCORE 페이지
- REDCORE T-SHIRT 제품 단독컷(메인) + 모델 착용컷(2번째)
- 사이즈별 장바구니
- 서버 측 가격/배송비 재계산
- 주문번호 생성 및 JSON 저장
- 주문 조회
- 관리자 주문 목록/상태 변경
- 원클릭 시작/종료 배치 파일

## 출시 전에 사용자가 해야 하는 것
- 실제 결제(PG) 계약/계정 발급 및 결제키 설정
- 실제 도메인/호스팅 배포
- 개인정보/환불/배송/통신판매 등 운영 정보 확정
- 필요하면 배송사 API 연동

위 항목은 계정, 인증값, 사업 운영 정보가 필요하므로 내가 임의의 값으로 실제 결제를 활성화하거나 법적/사업 절차를 대신 완료할 수 없습니다.
